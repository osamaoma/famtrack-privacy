Consent-Based Family Location Sharing

Opt-In Privacy Guarantee

Effective Date: October 6, 2026

At FamTrack, we believe that location sharing must strictly empower users rather than compromise their privacy. This Privacy Policy details how personal information and device location data are collected, used, processed, and protected within the FamTrack Android application.

1. Core Principles of Consent

FamTrack operates strictly on an opt-in, consent-first architecture:

  • Approval-Required Access: No user can view another person's location without explicit approval. Connection requests must be manually accepted by the target relative.
  • No Self-Approval: Watchers cannot approve connection requests on behalf of other users under any circumstances.
  • Instant Revocation: Users can revoke access or tap "Stop Sharing" at any time, instantly removing the watcher from authorized access lists.

2. Information We Collect

A. Personal Information

  • Account Credentials: We collect your email address and an encrypted password via Firebase Authentication to establish your user profile and securely manage your connections.

B. Location Data

  • Precise Background & Foreground Location: FamTrack uses Android's Fused Location Provider API to fetch device geographic coordinates (latitude and longitude).
  • Update Frequency: Location coordinates are periodically updated (approximately every 20 minutes during active background tracking) and during a final best-effort ping prior to a standard phone shutdown.
  • OpenStreetMap Processing: Coordinates are mapped using open-source OpenStreetMap (osmdroid) libraries for map visualization.

3. How We Use Your Information

We use the collected data strictly to deliver core app functions:

  • To authenticate user identity and prevent unauthorized access.
  • To display current and last-known location snapshots to authorized family members.
  • To evaluate security permissions using Firestore database rules, ensuring location reads are allowed only if a user's unique identifier (uid) exists in the target's allowedWatchers list.

4. Third-Party Services

FamTrack integrates trusted third-party infrastructure providers that comply with global data protection standards:

  • Firebase (Google LLC): Used for secure user authentication, real-time database storage (Cloud Firestore), and backend cloud infrastructure. [Google Privacy Policy]
  • OpenStreetMap / osmdroid: Used for rendering map tiles and rendering location pins on the client interface without selling user data. [OSMF Privacy Policy]

5. Data Access Control & Security Rules

Location data is stored securely in Firebase Cloud Firestore. Access control is enforced at the database level:

  • A watcher can only read a target user's location document if their uid is explicitly present in that document's allowedWatchers array.
  • When a user taps "Stop Sharing", their watcher's uid is immediately pruned from the array, revoking read permissions instantly.

6. Data Retention and Account Deletion

You maintain complete ownership of your personal data:

  • Account Deletion: Initiating "Delete My Account" permanently erases your user profile, stored location history, last-known coordinates, and active permissions from our databases immediately.

7. Children's Privacy

FamTrack requires explicit parental setup and mutual consent when used by minors. The app does not knowingly collect location data from children without explicit connection authorization by a parent or guardian on the child's device.
